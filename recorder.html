Allow microphone

One tap so Chrome remembers Allow for this extension. Then you return to your page.

How to use

  1. 1

    Allow the microphone on this tab (button above).

  2. 2

    You return to your page — this tab keeps listening in the background.

  3. 3

    In the side panel use Start, Pause, and Stop.

  4. 4

    Press Insert to paste text into the active field on the page.

Shortcuts: Ctrl+Shift+1 start · Ctrl+Shift+2 stop
