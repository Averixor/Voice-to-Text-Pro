Privacy Policy — Voice to Text Pro

Last updated: 2026-10-23

What this extension does

Voice to Text Pro is a Chrome extension that converts speech to text in the Chrome Side Panel, applies optional punctuation helpers, and can insert the draft into a page field you choose.

Speech recognition (Google Web Speech)

Recognition uses the browser Web Speech API (SpeechRecognition / webkitSpeechRecognition). In desktop Google Chrome this typically sends audio to Google’s speech recognition servers over the internet. An active network connection is required for recognition. The extension does not run a separate speech model on your device.

Local storage

The extension stores settings and the text draft in chrome.storage.local on your device: recognition language (language), punctuation level (autoPunctuation), draft text (textDraft), and the privacy consent flag (privacyConsentAccepted, set to true when the user accepts the in-panel notice before recording). This data is not uploaded by the extension to a first-party server.

Page access

The extension does not permanently inject scripts into every website. It injects helper scripts only after you take an explicit action (Insert in the side panel or the context-menu paste item), and may ask for optional host access for that site when needed to complete paste.

Permissions

  • activeTab / scripting — paste into the page after your gesture
  • storage — settings and draft
  • sidePanel — main UI
  • contextMenus — paste menu item
  • notifications — optional recording-started notice
  • optional host permissions — granted per site when paste needs them

Chrome Web Store listing

Chrome Web Store requires a publicly reachable HTTPS Privacy Policy URL. Host this document (or an equivalent page) and paste that URL into the store listing. The packaged privacy.html file alone is not enough for the listing field.
