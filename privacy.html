Privacy Policy — Voice to Text Pro

Last updated: 2026-10-24

What this extension does

Voice to Text Pro converts speech to text. The controls and the draft live in the Chrome side panel. Speech recognition itself runs in a recorder tab that the extension opens beside your page, because the side panel cannot reliably use the microphone. Optional punctuation helpers run locally in the panel. You can insert the draft into a page field you choose.

Speech recognition (Google Web Speech)

Recognition uses the browser Web Speech API (SpeechRecognition / webkitSpeechRecognition) inside the recorder tab. In desktop Google Chrome this typically sends audio to Google’s speech recognition servers over the internet. An active network connection is required for recognition. The extension does not run a separate speech model on your device. Closing the side panel stops recognition and closes the recorder tab after a short delay.

Microphone

The recorder tab asks Chrome for microphone access. That permission belongs to the extension, not to the website you are dictating into. The extension does not show a desktop notification when recording starts.

Local storage

The extension stores settings and the text draft in chrome.storage.local on your device: recognition language (language), interface language (uiLanguage), punctuation level (autoPunctuation), draft retention (draftRetention: keep, clear when the panel closes, or clear after 7 days), draft text (textDraft), when the draft was last saved (textDraftSavedAt), and the privacy consent flag (privacyConsentAccepted). Recorder tab ids needed while a dictation is in progress are kept in chrome.storage.session and disappear when the browser session ends. This data is not uploaded by the extension to a first-party server.

Page access

The extension does not permanently inject scripts into every website. It injects content.js only after you take an explicit action (Insert in the side panel or the context-menu paste item), including frames and open shadow roots when it can reach them. If the active tab URL is not visible to the extension, Insert asks you to grant optional access for http and https pages. Password fields and non-text inputs are not paste targets.

Permissions

  • activeTab / scripting — paste into the page after your gesture
  • storage — settings and draft
  • sidePanel — main UI
  • contextMenus — paste menu item
  • optional host permissions (http://*/*, https://*/*) — granted only when paste needs them

Smart punctuation

“Smart punctuation” is a local text helper. It is not a generative AI service. It capitalizes the start of a phrase and can add a period, question mark, or exclamation mark from fixed rules in the extension. Spell check is the browser’s built-in checker.

Chrome Web Store listing

Chrome Web Store requires a publicly reachable HTTPS Privacy Policy URL. Host this document (or an equivalent page) and paste that URL into the store listing. The packaged privacy.html file alone is not enough for the listing field.
